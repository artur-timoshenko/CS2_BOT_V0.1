# Bot Arena — полигон для обучения CS-бота

Без зависимостей: Node 18+ (сервер и симуляция), браузер (просмотр), Python stdlib (+numpy, если есть).

```
node server.js          # http://127.0.0.1:8080  (HOST=0.0.0.0 / PORT=8081 через env)
node test.js            # физика, урон, стены, ступеньки, бенчмарк
py python/arena.py      # смоук-тест клиента: 256 env, случайные действия
```

- `/` — играть самому против скриптового бота (та же симуляция, что при обучении).
- `/?watch=ID` — смотреть серверный env (0 — вид сверху, 1–9 — глаза игрока).

## Симуляция (`sim/core.js`)
Единицы и углы как в Source/CS2: дюймы, Z вверх, yaw 0 = +X, pitch + = вниз, 64 тика.
Движение по cvar-ам CS2 — все константы в объекте `CVARS`, их можно менять на лету. Сверено с
[Mapper's Reference Valve](https://developer.valvesoftware.com/wiki/CS:GO_Mapper%27s_Reference) и замерами сообщества
([zer0k-z](https://github.com/zer0k-z/cs2-movement-issue-bhop), [memorin](https://memorin.app/mechanics/movement-constants)); тесты в `test.js`:
- гравитация Source: половина до перемещения, половина после; функция прыжка сразу добавляет вторую половину →
  высота прыжка 54.65 (64 тика) / 55.83 (128); прыжок в приседе задаёт импульс целиком (+2.3);
- на какой блок можно запрыгнуть: стоя 54, в приседе 56, прыжок→присед 63, присед→прыжок 65 (как у Valve);
- присед — рампа 10 тиков (6.4/с), хитбокс переключается в конце; в воздухе центр смещается на 9 (ноги вверх/вниз);
- глаза 64.09 стоя / 46.08 в приседе, ступни на 0.03125 над полом, земля — пол в пределах 2 юнитов;
- разгон `sv_accelerate 5.5 × скорость оружия` (`sv_accelerate_use_weapon_speed 1`), трение 5.2, stopspeed 80,
  шаг 52% (AK 111.8), присед 34%; стрейф в воздухе (12, 30) ослаблен в 4 раза при подъёме 0..140 u/s;
- приземление: стамина `0.05 × скорость падения` временно режет максимум скорости (~80%, восстановление ~0.25 с),
  прыжок с распрыжки обрезает горизонтальную скорость до 1.1 × макс.; повторный прыжок ниже;
- края до 19 юнитов «прилипают», с 20 падаешь; урон от падения совпадает с таблицей Valve (300 → 24, 400 → 50, 500 → 71).
Вьюер: сырой ввод мыши, FOV как в CS2 (90° по горизонтали для 4:3), `?sens=` в единицах CS2, прыжок на колесо.
Стрельба по модели CS с числами из `scripts/weapons.vdata` CS2 (урон, скорострельность, бронебойность, падение урона,
`m_flInaccuracy*`, `m_flRecoveryTime*`, `m_flRecoil*`, время доставания и перезарядки):
- неточность = база (стоя/присед) + движение (от 34% до 95% макс. скорости) + в воздухе + штраф за выстрелы/прыжок/
  приземление; штраф падает в 10 раз за время восстановления, которое растёт с номером пули в очереди;
- разброс CS: случайная точка в круге неточности + в круге spread;
- отдача через aim punch: каждый выстрел толкает прицел, затухание по `weapon_recoil_decay2_exp/lin`, пули летят в
  «взгляд + 2×punch», камера показывает 45% (пули ложатся выше прицела, как в CS2). Последовательность толчков
  строится из seed/угла/силы оружия и одинакова от очереди к очереди. **Точная таблица спрея CS2 не воспроизведена**
  (её генерирует код игры) — форма похожа: прямой подъём ~8° к 8-й пуле, затем увод в сторону;
- Glock полуавтомат (одно нажатие — один выстрел, правило CS через счётчик выстрелов), AK автомат;
- все 66 предметов CS2 в `sim/weapons-cs2.js` (генерирует `node tools/import-weapons.js <Maps>/_source/weapons/weapons.vdata`):
  набор оружия на раунд — `new Env({ loadout: ['nova', 'deagle', 'knife'] })` (основное, пистолет, нож), во вьюере —
  в настройках (Esc). Дробовики: дробинки (`pellets`) летят отдельными лучами, заряжаются по одному патрону;
  у Glock 6 запасных магазинов, как в игре (в vdata 3);
- прицел (attack2 на AWP/SSG 08/SCAR-20/G3SG1 — 2 уровня, AUG/SG 553 — один): точность, разброс, скорость и FOV —
  значения `[1]` из vdata (AWP 0.081 → 0.002 рад, бег 200 → 100, FOV 40/10); AWP и SSG после выстрела выходят из
  прицела на передёргивание и возвращаются; перезарядка и смена оружия выбивают из прицела. Во вьюере — оверлей,
  руки скрыты, чувствительность × FOV/90 (`zoom_sensitivity_ratio 1`), у снайперок нет перекрестия, как в CS2;
- гранаты (`new Env({ grenades: ['hegrenade', 'flashbang', 'smokegrenade', 'molotov'] })`, до 4, флешек ≤ 2, CT
  получают зажигательную вместо молотова; по умолчанию нет — обучение не меняется): слот 4 (ещё раз — следующая),
  зажать ЛКМ/ПКМ/обе — чека, отпустить — бросок через 0.1 с с силой 1 / 0 (под себя) / 0.5 по формулам игры (750 × 0.9 ×
  (0.3 + 0.7·сила) + 1.25 × скорость игрока, прицел приподнят на 10°), гравитация 0.4, отскок 45%. HE — через 1.5 с,
  99 урона с гауссовым спадом до 350, стены защищают; флешка — 1.5 с, слепота до 4.87 с (меньше, если смотреть мимо
  или далеко), ослеплённый не видит врагов (в наблюдениях тоже); дым — когда остановится, 20 с, скрывает видимость, тушит
  огонь; молотов — при ударе о пол или через 2 с, 7 с огня радиусом 120, 40 урона/с; ложная — 15 с выстрелов оружием
  бросившего. Урона по своим нет (как у пуль). Размеры дыма/огня и кривая флешки — приближение, не замер в CS2;
- sub-tick как в CS2: момент нажатия клавиш, прыжка и выстрела внутри тика; выстрел берёт угол взгляда в момент клика;
- плавный присед (0.125 с, замедляется при спаме), хитбоксы и глаза опускаются вместе с ним.

## API (батч, JSON)
| запрос | тело | ответ |
|---|---|---|
| `POST /api/envs` | `{count, config}` | `{ids, obsSize, actionSize, nAgents}` |
| `POST /api/reset` | `{ids, seed?}` | `{obs[env][agent][obsSize]}` |
| `POST /api/step` | `{ids, actions[env][agent][10]}` | `{obs, rewards, dones, infos}` (авто-reset, `infos[i].final_obs`) |
| `GET /api/state/ID` | — | позиции/hp/события для визуализации |
| `POST /api/close` | `{ids}` | |

`config`: `opponent` (`bot` — скриптовый противник, `agent` — self-play, управляешь обеими командами),
`teamSize` (1–5), `frameSkip` (тиков на шаг, по умолч. 4), `botSkill` 0..1, `rays`, `maxSeconds`,
`map` (имя импортированной карты, напр. `"de_dust2"`).

Действие: `[вперёд -1..1, вбок -1..1, Δyaw°, Δpitch°, прыжок, присед, шаг, огонь, перезарядка, слот 0..3, moveFrac, fireFrac, attack2]`
(`moveFrac`/`fireFrac` — необязательный sub-tick момент 0..1, 0 = без sub-tick; `attack2` — ПКМ: режим очереди Glock / укол ножом).

## Настоящая карта (de_dust2) из своей копии CS2
Ассеты Valve в репозиторий не входят — карта берётся из твоей установленной игры.

1. Source2Viewer → `de_dust2.vpk` → Export glTF без сжатия (у нас уже лежит в `D:\04_FREELANCE\04_CS_BOT\03_Bot_V5\Maps\Dust_2`).
2. Импорт (≈12 с; пишет только `public/maps/de_dust2/{map.json,grid.bin.gz}`, сам экспорт не копируется — сервер
   отдаёт его из исходной папки). Точки спавна — центры `func_buyzone` из `de_dust2_d_physics.gltf`:
   ```
   node --max-old-space-size=8192 tools/import-map.js D:/04_FREELANCE/04_CS_BOT/03_Bot_V5/Maps/Dust_2/de_dust2_d.gltf --name de_dust2 --t -754,-824,150 --ct 200,2272,-80 --bounds -2600,-1400,-400,2200,3400,700
   ```
   Не твёрдыми по умолчанию считаются (`SKIP_DEFAULT` в `tools/import-map.js`): эффекты `csgo_effects` (пыль, пар, лучи),
   служебные `generic.vfx`, чёрные заглушки, наложенные надписи/пятна (`alpha:BLEND`), провода и листва.
   Фильтр проверяет строку «узел меш материал шейдер alpha:РЕЖИМ» каждого примитива.
   Опции: `--voxel 4` (точнее, медленнее; по умолч. 8), `--collision file.gltf` (отдельный меш коллизии),
   `--skip` (свой регэксп вместо `SKIP_DEFAULT`), `--bounds` (обрезка декора за картой), `--scale`.
   `_physics.gltf` из Source2Viewer — это только триггеры (закупка, пленты, 43 зоны `env_cs_place`, один клип),
   а не коллизия мира, поэтому коллизия строится из рендер-меша.
3. Играть: `/?map=de_dust2` (с текстурами, ~20 с) или `/?map=de_dust2&notex` (только геометрия, ~10 с).
   В HUD — координаты игрока в единицах CS2, их можно сверить с `getpos`.
   Обучение: `Arena(num_envs=256, map="de_dust2")`. Скорость: ~23k env-steps/с на ядро.

Координаты — те же, что в игре: если импорт правильный, `getpos` в CS2 и позиция в полигоне совпадают.
Коллизия — воксельная сетка: игрок стоит на верхней грани вокселя, т.е. до `--voxel` юнитов выше видимого пола;
щели уже вокселя закрыты. Если есть `surfaces.json` (`tools/surface-map.js`), глаза, хитбоксы и модель опускаются на
настоящий пол (`p.dz` — разница), коллизия остаётся на вокселях. Сверено с `getpos` в CS2 на 6 точках de_dust2:
высота глаз совпадает до 0.1–0.3 юнита (на пленте B 1.9), X/Y — точно. Проверка конвейера без файлов Valve: `node tools/boxes-to-glb.js out.glb` + импорт (есть в `test.js`).

Радар (`public/radar.js`), как в CS: вверху слева, по центру ты, карта поворачивается за взглядом; свои видны всегда,
враги — пока их видит кто-то из твоей команды (поле зрения + без стен). Картинка карты строится из воксельной сетки:
полы, до которых можно дойти от спавнов (ступеньки ≤ 18, спуск любой), яркость — высота; крыши и стены тёмные
(de_dust2 — ~0.2 с при загрузке). Встроенная карта — из коробок. Вид сверху (`0` в режиме наблюдения) — вся карта.
Склоны импортированной карты — воксельные ступеньки: в воздухе ступенька до одного вокселя поднимает игрока, а не
останавливает (иначе прыжок на подъёме гасил скорость; в Source игрок скользит вдоль плоскости склона).
Глаза и модель стоят на настоящем полу (`surfaces.json`): высоты клеток интерполируются между их центрами и берётся
максимум под следом хитбокса 32×32 (как в Source хитбокс на склоне опирается на верхний край), так что на склонах и
неровностях вид не скачет на каждой ступеньке вокселей; остаток (настоящие ступени) сглаживает вьюер за ~0.1 с.
На маршрутах бота по de_dust2: скачков глаз > 3 юнитов за тик 39 против 124 без карты поверхностей (было 150).

## Запуск
`npm start` → http://127.0.0.1:8080 — меню: «Играть с ботом» (`/?map=de_dust2`), список демок (`/?demo=имя`), встроенная
тестовая карта (`/?play`). Карта грузится облегчённой копией (текстуры ≤ 1024 px — четверть видеопамяти, иначе у de_dust2
~5 ГБ): `py tools/shrink-map-textures.py <Maps>/Dust_2_v21/maps/de_dust2.gltf` → `de_dust2.lite.gltf` + `lite/`;
`?hq` — оригинальные текстуры. Потеря контекста WebGL (переполнена видеопамять) — автоперезагрузка.
Загрузка de_dust2 ~10 с (было 110+): разбор анимаций оружия ищет кости по словарю (раньше — обходом всей сцены на каждую
дорожку), оружие демки грузится параллельно с картой, звуки оружия декодируются заранее только для своего снаряжения /
оружия демки, «прилипание» декалей (~60 с лучей по мешам) запоминается в браузере и при первом запуске идёт фоном после
загрузки. Статичные узлы карты не пересчитывают матрицы каждый кадр, разрешение рендера ≤ 1.5× экрана, одновременно
не больше 40 звуков (тихие отбрасываются). Замер в консоли: `loadStages` (этапы загрузки), `demoPerf` и `renderPerf`
(мс на кадр). На ×6: медиана 16.7 мс, отрисовка 13.7 мс, обновление сцены 3.8 мс.

## Демки CS2
```
py -m pip install demoparser2 zstandard           # один раз (zstandard — для .dem.zst)
py tools/import-demo.py match.dem [--out имя]      # или match.dem.zst → public/demos/имя.json.gz
```
Открыть: `/?demo=имя`. Игроки, взгляд, здоровье, броня, оружие, выстрелы, попадания, убийства и раунды — в координатах
CS2, на импортированной карте (`de_dust2` и т.д., иначе встроенная). Каждый ствол — своей моделью, анимациями и звуком
(папка `weapons`, ниже). Гранаты из демки: полёт (`parse_grenades`), взрывы HE/флешек, дым и огонь на всё время их жизни,
ослепление (белый экран у того, за кем смотришь), перезарядки (`weapon_reload` — анимация и звуки), смена оружия
(анимация доставания и звук). Ножи по отображаемому имени («Stiletto Knife» → `knife_stiletto`).
Раунды — с `begin_new_match` (разминка не считается), счёт — `team_rounds_total` игры после каждого раунда (идёт за
командой через смену сторон), названия команд — `team_clan_name`. Бомба: установка (`bomb_beginplant` → анимация
установки от 1-го и 3-го лица, 7 нажатий кода), лежит на месте установки, пищит всё чаще до взрыва (40 с; последние 10 с —
звук «10sec»), мигает красным, разминирование и взрыв со звуками CS2; брошенная бомба лежит, пока её не подберут.
HUD как в демо-плеере CS2: сверху спецназ слева, террористы справа — счёт, название команды и квадратик на игрока
(полоска HP, мёртвый — тусклый с ✕, выбранный — в рамке); в центре время раунда, после установки — значок бомбы,
мигающий с писком; в нижних углах строки игроков (HP-полоса, имя, оружие в руках, убийства); баннер победы раунда с
причиной. Перед просмотром грузится и прогревается (шейдеры, текстуры) всё оружие демки — без рывков при первом
появлении ствола. Управление: Space пауза,
←/→ 5 с, Shift+←/→ раунд, +/− скорость (0.25–8×, есть 6×), 1–5 спецназ / 6–0 террористы (или клик по квадратику / строке),
` вид сверху, V 3-е лицо;
таймлайн с отметками конца раундов (цвет победителя). Кадры по `--step` тиков (16/с), между ними интерполяция.
Раунды полигона в тот же формат: `node tools/record-demo.js [--map de_dust2] [--rounds 3] [--out имя]`.
Формат — в начале `public/demo.js`.

Вьюер: прицел обновляется каждый кадр, sim получает момент нажатий (sub-tick), игроки и камера интерполируются
между тиками; отдача сдвигает вид, следы пуль на стенах, кровь при попадании, вспышка у ствола.
F — осмотр оружия (клип `lookat01` от первого лица, звуки на своих кадрах: CS2 называет их по кадру, `ak47_inspect_f013`
= кадр 13 при 30 к/с; прерывается выстрелом, перезарядкой, прицелом, сменой оружия). Смена оружия — звук доставания
(`*_draw`, у кого нет — общий `movement`); перезарядка — магазин/затвор по долям перезарядки, у дробовиков звук на патрон.
Игроки (`public/avatar.js`): модели CS2 (раздел ниже), а без них — собственные низкополигональные модели с суставами — шаг по пройденному расстоянию
(ноги не скользят), шаг вбок/назад по направлению движения, покачивание и наклон корпуса, плавный присед,
поджатые ноги в воздухе и просадка при приземлении, наклон за прицелом и отдача корпусом, перезарядка левой рукой,
доставание, взмах ножом, плавное падение при смерти. От первого лица — руки с оружием: запаздывание за мышью,
покачивание «восьмёркой», отдача и вспышка на каждый выстрел, затвор Glock, смена магазина AK, доставание,
удары ножом поочерёдно, проседание при приземлении; свои ноги видны при взгляде вниз. V — камера от 3-го лица.

## Модели игроков и оружия из CS2
`public/models/models.json` — где лежат экспорты Source2Viewer (`srcDir`, сервер отдаёт их как `/models/src/…`, в
репозиторий не копируются) и какие файлы брать: агенты `[T, CT]` и папка оружия `weaponDir`. Нет файла или модели не
загрузились — вьюер берёт свои низкополигональные модели; `/?nomodels` — принудительно свои.

Оружие — по папке на каждый из 66 предметов CS2, имя = внутреннее имя игры (как в `sim/weapons-cs2.js`, иконках и демках):
```
Maps/weapons/index.json              имя → model, anims, shot, distant
Maps/weapons/deagle/model.glb        модель (только HD-корпус)
Maps/weapons/deagle/textures/        weapon_pist_deagle_color.png, _normal.png, _orm.png (≤ 2048 px)
Maps/weapons/deagle/anims.glb        клипы агента под этот ствол: draw, reload, reload_crouch… и vm_idle, vm_shoot1, vm_reload…
Maps/weapons/deagle/sounds/          shot_01.wav…, distant_01.wav, reload_out_01.wav, reload_in_01.wav… (гранаты: pin, throw,
                                     bounce, detonate, distant, fire, ring…)
Maps/_source/                        сырые выгрузки (glTF оружия, старый экспорт, weapons.vdata, звуки из pak01_dir.vpk)
```
Собирается из `_source` и полного экспорта агента (`models/agents/models/tm_phoenix/tm_phoenix.gltf`, у обоих агентов
одинаковые клипы и скелет), ~1 мин, затем текстуры ужимаются:
```
node --max-old-space-size=8192 tools/build-weapons.js [--only deagle,nova] [--sounds]   # --sounds: только звуки
py tools/shrink-textures.py D:/04_FREELANCE/04_CS_BOT/03_Bot_V5/Maps/weapons
```
AK, Glock и ножи грузятся сразу, остальное — при первом появлении в руках (пока грузится, виден AK/Glock/нож того же
класса). У агентов нет viewmodel-набора для USP-S и M4A1-S — берутся наборы P2000 и M4A4; гранаты без звука выстрела.
Там же ассеты интерфейса CS2 (экспорт Source2Viewer в `Maps/ui`): `tracer` — `bullet_tracer` (PNG) для трассеров;
`radars.<карта>` — радар `panorama/images/overheadmaps/<карта>_radar_psd` (PNG) + `resource/overviews/<карта>.txt`
(`pos_x`/`pos_y` — мировые координаты левого верхнего угла, `scale` — юнитов на пиксель). Нет радара для карты —
он строится из воксельной сетки (ниже).
`sounds` — звуки CS2 (WAV/MP3; `.vsnd_c` браузер не играет — экспортировать с декомпиляцией), по группам:
`step_<поверхность>` / `land_<поверхность>` (concrete, sand, dirt, gravel, grass, wood, tile, metal, metal_grate, glass,
carpet, mud, rubber; нет своей — берётся шаг этой поверхности, потом общий), `suit_t`/`suit_ct` (шорох снаряжения под
каждым шагом), `jump`, выстрелы каждого ствола (из `weapons/index.json`: группа = имя оружия, + `<имя>_distant` —
дальний слой), `hit`, `headshot`, `death`, `kill`,
`headshot_kill`, `ambient` (все играют петлёй одновременно), `ambient_random` (раз в 6–18 с). Пустая группа — тишина.
Распространение — по звуковым событиям CS2 (`soundevents/game_sounds_*.vsndevts` из pak01_dir.vpk, Source2Viewer-CLI
с `-d`, → `node tools/import-soundevents.js <папка>` → `<Maps>/sounds/soundevents.json`): у группы, чей файл игра
проигрывает из события, — его кривая громкость/расстояние (`distance_volume_mapping_curve`, шаги — до 1100, AK — до
9000 с дальним слоем 800–2900), дочерние события играют вместе (дальний слой выстрела, хвост взрыва), стена между
источником и ухом (луч по карте коллизий) глушит по `occlusion_intensity` — тише и фильтр низких частот; вдали воздух
срезает верха; реверберация по `reverb_wet`. Абсолютные громкости игры идут через её микшер, поэтому уровень группы
свой, от события — только множитель 0.25–1.2. Соответствие переименованных файлов оружия — `weapons/origins.json`.
Как в CS2: свои звуки (шаги, выстрелы) — «в голове», чужие — с направлением (HRTF, слушатель — камера) и громкостью до
нуля ровно на дальности слышимости (шаги/приземления ~1100, выстрелы — через карту, дальше 1500–1800 — дальний слой);
шаги только бегом, каждые 0.3 с (`public/sound.js`). Поверхность под ногами — `public/maps/<карта>/surfaces.json`
(по именам материалов glTF, клетки 16 юнитов): `node --max-old-space-size=8192 tools/surface-map.js de_dust2` (~7 с).

Экспорт агента (glTF ~1 ГБ, ~2200 анимаций) ужимается до нужных 115 клипов (≈30 МБ, текстуры остаются рядом):
```
node --max-old-space-size=12000 tools/pack-model.js D:/04_FREELANCE/04_CS_BOT/03_Bot_V5/Maps/models/agents/models/ctm_sas/ctm_sas.gltf
```
GLB пишется рядом с исходником (`--out`, `--anims РЕГЭКСП` — по желанию). `tm_phoenix.glb` уже был в таком виде.

Что играет (`public/avatar.js`): бег/ходьба/присед по 8 направлениям со смешиванием по углу и скорости, шаг по длине
root motion клипа (ноги не скользят), прыжок, доставание и перезарядка по прогрессу из симуляции, удар ножом, наклон корпуса
за прицелом и отдачей. Оружие крепится к кости `wpn`. От первого лица — руки агента с анимациями viewmodel CS2 (доставание,
перезарядка с магазином, выстрел, взмахи ножом) плюс покачивание/запаздывание. Ограничения экспорта: клипы `idle_*` и
`shoot_*` — аддитивные слои, сами по себе не годятся, поэтому стойка на месте собрана из 8 направлений ходьбы, а выстрел
от 3-го лица — только отдача корпуса; клипов смерти нет (в CS2 рэгдолл) — тело просто падает. У SAS нет набора
viewmodel для `knife_default_ct` — используется набор T-ножа.

Встроенная карта `sim/map.js` — оригинальный лэйаут из коробок, используется, если `map` не указан.
