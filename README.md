# Bot Arena — полигон для обучения CS-бота

Без зависимостей: Node 18+ (сервер и симуляция), браузер (просмотр), Python stdlib (+numpy, если есть).

```
node server.js          # http://127.0.0.1:8080  (HOST=0.0.0.0 / PORT=8081 через env)
node test.js            # физика, урон, стены, ступеньки, бенчмарк
py python/arena.py      # смоук-тест клиента: 256 env, случайные действия
```

- `/` — играть самому против скриптового бота (та же симуляция, что при обучении).
- `/?watch=ID` — смотреть серверный env (0 — вид сверху, 1–9 — глаза игрока).
